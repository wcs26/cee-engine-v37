## 🛒 Procédure EUIPO en ligne (~30 min)

1. Aller sur https://euipo.europa.eu/eSearch/ → vérifier antériorité du nom choisi
2. Aller sur https://euipo.europa.eu/ohimportal/fr → "Déposer une marque"
3. Créer un compte (peut être nouveau)
4. Choisir "5-step EUTM" (parcours simplifié 5 étapes)
5. Étape 1 : Identité du déposant → coller le bloc ci-dessus
6. Étape 2 : Type de marque → "Marque verbale"
7. Étape 3 : Saisir le **nom choisi** (ex: "Cumeo")
8. Étape 4 : Choisir 3 classes Nice (9, 35, 42) → coller les libellés ci-dessus
9. Étape 5 : Paiement carte bancaire 1 050 €
10. Confirmation par e-mail → numéro de dossier EUTM

**Délai** : 4-6 mois pour examen + opposition publique 3 mois.
Statut "marque enregistrée" + certificat délivré ensuite.
