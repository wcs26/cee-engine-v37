**RÈGLE** : CEE Engine est un **audit prédictif, proactif, intelligent**. Les compléments (CRM, comparateur acheteurs, documents PDF, veille réglementaire, export, etc.) ne doivent ni changer cette nature ni compliquer le flux principal.

**Why :** le différenciant marché n'est pas "énième plateforme CEE avec CRM intégré" (Renolib, Effy, France CEE, NR-PRO couvrent déjà ça). C'est la **capacité de diagnostic proactif** — détection automatique des gisements, 224 fiches, 150+ questions expertes, enrichissement open data (Cadastre IGN, BD TOPO, DPE, audits ADEME). Tout ce qui pollue ce flux dilue le positionnement.

**How to apply :**
- Les fonctions annexes (CRM, comparateur, mandat PDF, etc.) sont utiles MAIS doivent être **compartimentées** : panneau séparé, modal, drawer latéral, onglet secondaire — jamais inlinées dans le parcours d'audit (Step 1 à Step 5).
- Le parcours audit (Step 1 → Step 5) reste visuellement pur : identification → gisements → sélection → opérations → rapport.
- Chaque ajout doit se demander : "est-ce que ça sert l'audit prédictif/proactif/intelligent ?" Si oui → intégrer au flux. Si non → compartiment séparé.
- Pas de surcharge de boutons, pas de cards qui s'accumulent dans les étapes. Un point d'accès unique pour les outils annexes (ex: "🧰 Outils" dans le header).
